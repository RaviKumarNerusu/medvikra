# MedGenesis image assets

Replace the placeholder paths with company-provided files using these exact names:

| Filename | Website section | Recommended dimensions |
|---|---|---|
| `logo.png` | Brand | 400 x 120 |
| `hero-device.png` | Hero product | 1000 x 900 |
| `device-front.png`, `device-side.png` | Specifications | 900 x 900 |
| `device-demo.jpg`, `prototype-demo.jpg` | Demo gallery | 1200 x 900 |
| `diagnostic-workflow.png` | Workflow/gallery | 1400 x 900 |
| `iop-measurement.png`, `visual-field-testing.png`, `focus-assessment.png` | Assessment cards | 800 x 600 |
| `certificate-1.jpg`, `certificate-2.jpg` | Gallery | 1200 x 900 |
| `team.jpg`, `about-company.jpg` | About | 1200 x 900 |

PNG, JPG, and WebP are supported. Images are loaded automatically when uploaded with the exact filename; no component changes are needed. Do not upload unverified certificates or claims as published evidence.
